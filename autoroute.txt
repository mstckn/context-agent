# MODE 2 — HYBRID

# 6. ROUTER GOAL

Do NOT optimize:

"always use the cheapest model."

Optimize approximately:

LOWEST EXPECTED COST TO A CORRECT VERIFIED RESULT.

Consider:

* model call cost
* retry probability
* escalation probability
* validation cost
* task risk
* model capability
* previous failures
* expected success probability

Example:

A cheap model requiring three retries may cost more than using a stronger model once.

Start deterministic.

Do not build speculative machine learning for router decisions in this phase.

Collect telemetry first.
